Положите сюда файл `trapa.schem`.

При использовании ловушки её X/Z Origin совмещается с блоком под игроком.
Высота определяется автоматически: верхний непустой слой схематики ставится
ровно на один блок выше самой высокой поверхности в её площади. Поэтому основная
часть конструкции находится в земле, а над рельефом остаётся только её верхний
край. Игрок при активации остаётся на месте.

Воздушные клетки центральной ямы принудительно очищают обычные блоки земли,
траву и растения — внутри ловушки всегда остаётся свободное пространство.
Пустоты заполняются только в четырёх угловых участках конструкции: для них
берётся материал ближайшего блока земли под той же колонкой. Центральная яма
никогда не заполняется этими блоками.

Для корректного центрирования в WorldEdit задайте Origin по центру ловушки:

1. Встаньте в центральную точку конструкции.
2. Выполните `//copy -e` с этой точкой как origin.
3. Сохраните результат как `trapa.schem`.

Файл можно положить в эту папку проекта до сборки. На сервере также поддерживается
файл `plugins/ElytrixItem/schem/trapa.schem`; он имеет приоритет над встроенным.
